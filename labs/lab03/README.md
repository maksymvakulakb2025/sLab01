## Опис предметної області
REST API сервіс для обліку спрацювань засобів захисту інформації. 
Проєкт використовує FastAPI та реляційну базу даних SQLite. Реалізовано шар роботи з базою даних для взаємодії через параметризовані SQL-запити без використання ORM.

* **Одиниця вимірювання (value):** кількість подій (events) - ціле число $\ge$ 0.
* **Категорії:** `firewall` (міжмережевий екран), `ids` (система виявлення вторгнень), `antivirus` (антивірусний захист).
* **Порогове значення:** 15 спрацювань.
* **Статуси опрацювання (status):** `new`, `in_progress`, `done`.
